WEB DEVELOPMENT • FULL-STACK PROJECT

PortfolioForge

A full-stack portfolio builder designed to allow users to create, manage, customize and generate their own professional portfolio.

PHP MySQL HTML CSS JavaScript Dompdf Composer

01 • PROBLEM

What problem was I solving?

Creating and maintaining a professional portfolio usually requires editing static files or depending on external portfolio platforms.

I wanted to build a system where users could manage their portfolio information through an application instead of manually editing the website every time.

02 • APPROACH

How did I approach it?

I divided the application into different functional parts such as authentication, profile management, projects, activities, customization and PDF generation.

Each part communicates with the backend and database to create a complete portfolio management system.

03 • ARCHITECTURE

How does the system work?

User
→
HTML / CSS / JavaScript
→
PHP Backend
→
MySQL Database

The frontend provides the interface, PHP handles application logic and requests, and MySQL stores user and portfolio data.

04 • TECHNOLOGIES

Why these technologies?

HTML

Used to structure the application's pages and portfolio content.

CSS

Used to create the visual layout, styling and portfolio templates.

JavaScript

Used to add client-side interactions and dynamic behaviour.

PHP

Used for server-side logic, authentication, database operations and application flow.

MySQL

Used to store and manage user profiles, projects and other portfolio information.

Dompdf

Used to generate downloadable A4 PDF portfolios from the application.

05 • KEY FEATURES

What did I implement?

  • User registration and login
  • Session-based authentication
  • Profile management
  • Project creation, editing and deletion
  • Activities and certifications management
  • LinkedIn and GitHub profile integration
  • Portfolio customization
  • Multiple portfolio templates
  • Theme color customization
  • Portfolio preview
  • A4 PDF generation
  • Database-driven portfolio content

06 • CHALLENGES & SOLUTIONS

What problems did I solve?

Database & Deployment

While deploying the application, database configuration and hosted database differences had to be identified and corrected.

Missing Data

Missing profile and project data was investigated by checking the database structure and application queries.

PDF Generation

Dompdf and Composer dependencies had to be correctly configured so PDF generation worked on the deployed application.

Application Paths

Redirect, logout and CSS path issues were identified and corrected during deployment.

07 • RESULT

What did I build?

The final result is a working full-stack portfolio builder where users can manage their portfolio information, customize its appearance, preview it and generate a PDF version.

The project was also deployed so that the application could be tested outside the local development environment.
