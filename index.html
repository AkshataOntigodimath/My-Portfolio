How I Build

I don't start with a technology. I start with a problem and work towards a practical solution.

01

Understand

Identify the problem, requirements and expected outcome.

02

Plan

Break the problem into smaller parts and decide how each part should work together.

03

Build

Choose suitable technologies and implement the solution step by step.

04

Test & Solve

Test the system, investigate problems and improve the implementation until it works reliably.

05

Explain

Document how the system works, why technologies were chosen and what was learned.
